# Silo Terminal Theme

A dark, black-green phosphor VS Code color theme, based on the color palette from
[onehorizonai/silo-terminal](https://github.com/onehorizonai/silo-terminal).

Black-green background, pale phosphor text, brighter cyan/blue command output,
and yellow-green status colors.

## Install

1. Open VS Code.
2. Run `Extensions: Install from VSIX...` from the Command Palette.
3. Select the `.vsix` file.
4. Select the theme via `Preferences: Color Theme` -> **Silo Terminal**.
